# Thư mục dữ liệu phim tạm thời

Đồng đội đặt dữ liệu đã chuẩn bị vào thư mục này khi làm local:

```text
NMCMP/data/incoming-videos/ten-phim-khong-dau/
```

File video, poster, backdrop, phụ đề và `metadata.json` trong các thư mục phim sẽ không được đưa lên GitHub. Chỉ hai file hướng dẫn trong thư mục này được lưu trong Git.

Đọc thêm: [`docs/movie-data-preparation.md`](../../docs/movie-data-preparation.md).
